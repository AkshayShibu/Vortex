Vortex — AI-Powered Project Management System

Intelligent Project Management for Agile Teams, Hackathons & Startups
AI-powered task generation • Smart workload balancing • Burndown analytics • Kanban workflow • Team collaboration

Overview
Vortex is a modern AI-powered project management platform built with Django that combines traditional agile workflows with advanced AI capabilities.
It helps teams:
Generate project tasks automatically using AI
Balance workloads intelligently
Track deadlines proactively
Visualize progress with analytics
Collaborate efficiently with role-based access
Designed for:
 *Hackathon teams
 *Agile software teams
 *Student projects
 *Startup collaboration
 *Product development teams
